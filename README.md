# ARABIC BARBERSHOP

Демонстраційний адаптивний сайт на React + Vite. Інтерфейс українською. Усі майстри, ціни й години тестові. Форма працює локально, без сервера, надсилання даних або реального бронювання.

## Запуск

npm install
npm run dev

На Windows із обмеженою політикою PowerShell: npm.cmd install та npm.cmd run dev.

## Production

npm run build
npm run preview

Фотографії: ілюстративні стокові зображення з images.unsplash.com; не представляють ARABIC BARBERSHOP або роботи демонстраційних майстрів. Шрифти завантажуються з Google Fonts. Для зображень і вебшрифтів потрібне підключення до інтернету.

## Підготовка GitHub та Render Static Site

Завантажуйте вихідні файли: `src/`, `index.html`, `package.json`, `package-lock.json`, `.gitignore` та `README.md`. Зберігайте `package-lock.json` у репозиторії для відтворюваного встановлення залежностей. Папки `node_modules/` та `dist/` генеруються локально й виключені з Git разом із файлами оточення та локальними обліковими даними.

Проєкт не потребує API-ключів, бази даних або змінних оточення. Не додавайте секрети до клієнтського коду або змінних `VITE_*`: вони доступні відвідувачам у зібраному сайті. `.gitignore` застосовується до Git; під час ручного завантаження через GitHub обирайте лише перелічені вихідні файли.

Після завантаження репозиторію на GitHub створіть у Render сервіс типу **Static Site** та підключіть репозиторій:

- **Root Directory:** залишити порожнім, якщо `package.json` у корені репозиторію.
- **Build Command:** `npm ci && npm run build`
- **Publish Directory:** `dist`
- **Environment Variables:** не потрібні.
- **Start Command:** не потрібна для Static Site; `npm run dev` і `npm run preview` призначені для локального запуску.

Навігація використовує якорі (`#services`, `#team` тощо); правила переписування маршрутів не потрібні. Форма запису залишається локальною демонстрацією після публікації. Для фотографій Unsplash і шрифтів Google Fonts потрібен доступ до інтернету.

Перевірка перед публікацією: `npm ci`, потім `npm run build`. Результат — каталог `dist/`.

Документація: https://render.com/tutorials/web-service-vs-static-site/static-sites

Підготовка цих файлів сама по собі не створює репозиторій GitHub і не запускає публікацію в Render.
